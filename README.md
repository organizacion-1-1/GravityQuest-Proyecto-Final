# GravityQuest-Proyecto-Final
GravityQuest es un juego educativo interactivo en Kotlin para aprender física. En lugar de dar respuestas, reta al usuario a calcular problemas de caída libre. Cuenta con 3 niveles de dificultad: fácil (caída libre), medio (hacia abajo) y difícil (hacia arriba). Incluye pistas, puntuación y resolución paso a paso para un aprendizaje real y sólido.
